# Denker web

This is Denker's only product workspace. It contains the local Next.js App Router application, its shadcn/ui primitives, and its Jest/React Testing Library tests.

Run development and validation commands from the repository root:

```bash
pnpm dev
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

The current shell is intentionally neutral. Product state, persistence, and user flows are introduced by later tasks.
